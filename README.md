# AI-Powered Enterprise Data Detective

A tool that profiles enterprise transaction data, audits it for suspicious activity, and lets an analyst interrogate it in plain English — combining data engineering with an LLM (Claude) for natural-language querying. Built as a portfolio project for Forward Deployed Engineer (FDE)–style work.

## What it does

- **Data profiling** — loads a CSV and reports rows, columns, types, missing values, duplicates, and date range.
- **Anomaly / fraud detection** — flags suspicious transactions (amount outliers, large round numbers, velocity bursts, duplicate charges, high-risk countries, off-hours activity), each with a plain-English reason.
- **Natural-language Q&A (AI)** — ask a question like "which 5 accounts spent the most?" and Claude writes a safe SQL query, run with DuckDB, returned as a table.

## Tech stack

- Python + pandas — data handling and detection logic
- DuckDB — fast in-process SQL over the CSV
- Claude API (Anthropic) — natural-language to SQL
- Streamlit — simple web UI

## Project structure

    enterprise-data-detective/
    ├── data/
    │   ├── generate_sample_data.py   # creates synthetic demo transactions
    │   └── transactions.csv          # generated sample data
    ├── detective/
    │   ├── profile_data.py           # data-quality profiler
    │   ├── detect_anomalies.py       # statistical + rule-based fraud flags
    │   └── ask_claude.py             # natural-language -> SQL via Claude
    ├── app.py                        # Streamlit UI
    └── requirements.txt

> Note: the sample data is synthetic, generated by the script in this repo, with a small number of suspicious transactions deliberately injected. It is not real customer data.

## How to run

    pip install -r requirements.txt
    python data/generate_sample_data.py
    python detective/detect_anomalies.py data/transactions.csv
    streamlit run app.py

For the AI feature, set your Claude API key:

    export ANTHROPIC_API_KEY=sk-ant-your-key-here
