# 🕵️ AI-Powered Enterprise Data Detective

> **Built for Forward Deployed Engineer (FDE)-style work** — deploy fast, interrogate any dataset without a warehouse, and answer business questions in minutes using natural language.
>
> A Python + AI tool that **profiles enterprise transaction data**, **flags anomalies and fraud**, and lets analysts **interrogate data in plain English** — combining data engineering with the Claude LLM for natural-language SQL querying.
>
> ---
>
> ## ✨ What It Does
>
> | Feature | Description |
> |---|---|
> | 📊 **Data Profiling** | Auto-reports rows, columns, types, missing values, duplicates, and date range from any CSV |
> | 🚨 **Anomaly / Fraud Detection** | Flags suspicious transactions using 6 rule-based detectors — each with a plain-English reason |
> | 🤖 **Natural-Language Q&A** | Ask "which 5 accounts spent the most?" → Claude writes safe SQL → DuckDB runs it → returns a table |
>
> ### 🚨 Fraud Detection Rules
> - **Amount outliers** — transactions far above statistical norm (mean + 3σ)
> - - **Large round numbers** — suspiciously clean amounts ($5,000, $10,000)
>   - - **Velocity bursts** — same account, 3+ transactions within 1 hour
>     - - **Duplicate charges** — same account + amount + day, charged twice
>       - - **High-risk countries** — transactions from known fraud-prone regions
>         - - **Off-hours activity** — transactions between 11 PM – 5 AM

> ## 🚀 How to Run
>
> ```bash
> pip install -r requirements.txt
> python data/generate_sample_data.py
> python detective/detect_anomalies.py data/transactions.csv
> streamlit run app.py
> ```
>
> For the AI Q&A feature, set your Claude API key:
> ```bash
> export ANTHROPIC_API_KEY=sk-ant-your-key-here
> ```
