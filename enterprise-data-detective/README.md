# AI-Powered Enterprise Data Detective

A tool that ingests enterprise transaction data and helps an analyst **profile it, audit it for suspicious activity, and interrogate it in plain English** — combining classic data engineering with an LLM (Claude) for natural-language querying.

Built as a portfolio project for **Forward Deployed Engineer (FDE)**–style work: taking messy real-world data and turning it into a working, end-to-end tool.

## What it does

1. **Data profiling** — loads any CSV and reports row/column counts, data types, missing values, duplicates, numeric stats, and the date range. The first thing you do with an unfamiliar dataset.
2. **Anomaly / fraud detection** — flags suspicious transactions using statistical and rule-based checks (amount outliers, large round numbers, velocity bursts, duplicate charges, high-risk countries, off-hours activity). Every flag includes a plain-English reason.
3. **Natural-language Q&A (AI)** — ask a question like *"which 5 accounts spent the most in March?"* and Claude writes a safe SQL query, which is run with DuckDB and returned as a table.

## Tech stack

- **Python** + **pandas** — data handling and the detection logic
- **DuckDB** — fast in-process SQL over the CSV
- **Claude API (Anthropic)** — natural-language → SQL
- **Streamlit** — simple web UI

## Setup

    # 1. Install dependencies
    pip install -r requirements.txt

    # 2. Generate the sample data
    python data/generate_sample_data.py

    # 3. (For the AI feature) add your Claude API key
    cp .env.example .env
    # then edit .env and paste your key, OR:
    export ANTHROPIC_API_KEY=sk-ant-your-key-here

## Usage

Run the individual pieces from the command line:

    python detective/profile_data.py data/transactions.csv
    python detective/detect_anomalies.py data/transactions.csv
    python detective/ask_claude.py "top 5 merchants by total spend"

Or launch the full app:

    streamlit run app.py

## How the AI part works

The natural-language question is sent to Claude together with the table
schema. Claude returns a single SQL query, which is validated to be
read-only (`SELECT` only) before being executed with DuckDB. This keeps the
LLM in the loop for *understanding the question* while keeping execution
deterministic and safe.
